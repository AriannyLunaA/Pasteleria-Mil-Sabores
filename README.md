🌸 Pastelería 1000 Sabores - Plataforma E-commerce 🌸



Este proyecto consiste en el desarrollo frontend de una tienda online para "Pastelería 1000 Sabores", elaborada en el marco de la celebración de su 50 aniversario. El objetivo principal es renovar su sistema de ventas a través de una plataforma de e-commerce moderna y accesible que conecte su historia tradicional con las nuevas tecnologías.

El sitio permite a los usuarios:

 Explorar un catálogo detallado de productos.

 Personalizar pedidos de repostería.

 Acceder a un sistema de descuentos por registro.

🛠️ Tecnologías y Arquitectura
A nivel técnico, la interfaz está construida mediante trabajo colaborativo utilizando:

HTML5 Semántico: Para la estructuración sólida y accesible del contenido.

CSS3 (Hojas de estilo externas): Para el diseño visual y la experiencia de usuario (UX/UI).

JavaScript: Para gestionar la interactividad y la validación precisa de los formularios de usuario.
